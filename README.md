## 🛠️ What I've Built

- 👷 **AI Site Assessment Tool — QS Remedial**
  Turns voice notes and site photos into a fully structured scope of works and itemised quote in under 60 seconds. Built with Next.js and the Claude API — multimodal input, confidence-flagged line items, photo evidence mapping, and cost-of-inaction estimate. Live at [qs-remedial.vercel.app](https://kamleshhhkale-qs-remedial.vercel.app).

&nbsp;

- 📱 **Visual Inspection System — PHI Technologies**
  AI-powered defect detection and grading of mobile devices deployed into live retail kiosks for trade-in and insurance workflows. Applied DINOv2 for self-supervised feature extraction, CGANs for synthetic data generation, PyTorch training pipelines, Docker containerisation, and AWS deployment with REST APIs. Reduced labelled data requirements by 40%.

&nbsp;

- 🏨 **Daily Operations Briefing Generator — Zenithh Ops**
  Eliminates 30–45 minutes of daily manual reporting for hospitality operations managers. Paste raw exports from any system and receive a structured executive briefing in under 10 seconds. Built with Next.js, TypeScript, and the Claude API. Live at [ops-briefing-generator.vercel.app](https://kamleshhhkale-ops-briefing-generator.vercel.app).

&nbsp;

- 🛍️ **NLP Product Recommendation System — GlamourWear**
  End-to-end ML pipeline — text preprocessing, Logistic Regression, 89.34% accuracy (5-fold CV) — deployed as a live Flask web app where users browse items, submit reviews, and get real-time recommendation predictions. 🎥 [Watch Demo](https://drive.google.com/file/d/1Bbo5P5yJ8iXmYyGdt6hwZPHsfPh_IJ80/view?usp=sharing)

&nbsp;

- 📈 **Pharmaceutical Expenditure Forecasting — SARIMA**
  Complete time series pipeline in R — stationarity testing, BIC model selection, Ljung-Box diagnostics. Selected SARIMA(4,1,1)×(2,1,1)[12] from 7 candidates and validated 10-month forecasts on Australian PBS corticosteroid data.

&nbsp;

- 📊 **Australian Scam Report Dashboard**
  Interactive R Shiny dashboard exploring scam patterns across six Australian states using 45,306 rows of real 2024 ACCC Scamwatch data — KPI overview, age-group heatmap, and financial loss bubble plot. Live at [shinyapps.io](https://kamleshhhkale.shinyapps.io/project/).
