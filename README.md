## 🛠️ What I've Built

**AI Site Assessment Tool — QS Remedial**
Built a field assessment tool that turns voice notes and site photos into a structured scope of works and itemised quote in under 60 seconds. Assessors record voice observations, upload photos, and the tool uses the Claude API with multimodal analysis to return a fully structured quote — line items, confidence flags, photo evidence mapping, and cost-of-inaction estimate. Live at [qs-remedial.vercel.app](https://kamleshhhkale-qs-remedial.vercel.app).

**Visual Inspection System — PHI Technologies**
Worked on AI-powered inspection systems deployed into live retail kiosks for real-time defect detection and grading of mobile devices used in trade-in and insurance workflows. Built PyTorch training pipelines, applied DINOv2 for self-supervised feature extraction to reduce labelled data dependency, generated synthetic training images using CGANs, containerised models with Docker, and deployed on AWS with REST API endpoints. Reduced labelled data requirements by 40%.

**Daily Operations Briefing Generator — Zenithh Ops**
Built an AI tool that eliminates 30–45 minutes of daily manual reporting for hospitality operations managers. Paste raw exports from any system — PMS, POS, rostering, finance — and receive a structured executive briefing in under 10 seconds. Built with Next.js, TypeScript, and the Claude API. Live at [ops-briefing-generator.vercel.app](https://kamleshhhkale-ops-briefing-generator.vercel.app).

**NLP Product Recommendation System — GlamourWear**
End-to-end ML pipeline in Python — text preprocessing, Logistic Regression, 89.34% accuracy (5-fold CV), deployed via Flask web app. Users can browse items, submit reviews, and receive real-time recommendation predictions from the trained model. 🎥 [Watch Demo](https://drive.google.com/file/d/1Bbo5P5yJ8iXmYyGdt6hwZPHsfPh_IJ80/view?usp=sharing)

**Pharmaceutical Expenditure Forecasting — SARIMA**
Rigorous time series pipeline in R. ADF/KPSS stationarity tests, BIC model selection, Ljung-Box diagnostics. Selected SARIMA(4,1,1)×(2,1,1)[12] from 7 candidate models and validated 10-month forecasts on Australian PBS corticosteroid data.

**Australian Scam Report Dashboard**
Interactive R Shiny dashboard exploring scam patterns across six Australian states using 45,306 rows of real 2024 ACCC Scamwatch data. Four tabs covering state-level KPIs, a scam-type-by-age heatmap, a bubble plot of financial loss vs report volume, and data references. Live at [shinyapps.io](https://kamleshhhkale.shinyapps.io/project/).
